# 高精度四则运算

一份关于**高精度（大整数）四则运算**的完整学习笔记，C++ 实现。

从「为什么需要高精度」讲到「怎么写对、写快」，覆盖原理推导、可运行代码、复杂度分析和常见坑点。

## 关于笔记里的数字

笔记中给出的边界值都不是估的，是算出来并验证过的。例如：

- `mul_short` 里乘数 `b` 的上界是 **214748364**（由 $10b \le \texttt{INT\_MAX}$ 推出），超过就**静默算错**——不崩溃、不报错；
- 文章那套 `LEN = 1004` 的模板无法承受两个 1000 位数相乘（乘积最多 2000 位）；
- `sub` 只对 $a \ge b$ 有效，输入 `1 2` 会打印出 `/` 后跟 1003 个 `9`。
